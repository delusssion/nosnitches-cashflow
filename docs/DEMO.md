# Сценарий демо (5 минут)

Подготовка: `cd web && npm ci && npm run dev`, открыть http://localhost:5173. Всё работает на демо-данных `testdata/samples/` (не эталоны).
Автоматический прогон этого сценария со скриншотами: `cd web && npx playwright test` → `docs/screenshots/`.

| # | Что кликнуть | Что сказать |
|---|---|---|
| 1 | «Портфель» → **Загрузить демо** | Калькулятор отдаёт CSV будущих платежей по каждой сделке. Просмотрщик разбирает его в фоновом потоке — 100 000 сделок открываются за секунды, интерфейс не замирает. |
| 2 | Показать плашки и «Поток по месяцам» | Плашки — итоги по портфелю, красная — сделки, где после последнего платежа остался долг: у нас их 0. На графике активы над осью, депозиты под осью. |
| 3 | Клик по строке **DEMO-ANN-001** | Аннуитет на временной шкале: синие флажки — тело, оранжевые — проценты, пунктир — дата расчёта. Остаток ступенькой убывает ровно до нуля — закрывающий платёж гасит хвост. |
| 4 | «Портфель» → **DEMO-FLT-002** | Плавающая ставка: зелёные флажки — репрайсинг, подписана новая ставка — ключевая ЦБ + маржа. В таблице событий repricing идёт раньше процентов того же дня, как в контракте. |
| 5 | «Сверка» → **Демо-сверка** | Сверяем результат движка с эталоном по ключу сделка + дата + тип + поток, допуск 1 копейка. Все сделки зелёные. Если поменять в эталоне сумму на копейку и поставить допуск 0,005 — строка сразу краснеет. |
| 6 | Вернуться в «Портфель» | Итог: N сделок, M событий, сумма тела совпадает с остатками на дату расчёта, ненулевых остатков нет. Следующий шаг — тот же экран на синтетическом портфеле из `tools/gen-portfolio`. |

## Критерии приёмки движка

Источники: [CONTRACT.md](CONTRACT.md) (форматы 3–4, гипотезы), задачи бэкенда (B4, B6, B10), [METHODOLOGY.md](METHODOLOGY.md).

### 1. Сверка с эталонами

- Ключ строки: `deal_id + payment_dttm + payment_type + stream`; при дублях ключа — по порядковому номеру.
- Допуск: $|\Delta\,\text{amount}| \le 0{,}01$ и $|\Delta\,\text{principal\_after}| \le 0{,}01$.
- Нет строк «нет в движке» и «лишнее в движке», включая `repricing` / `sub_repricing`.
- Проверка: экран «Сверка» просмотрщика (`web/`) или интеграционный тест движка по всем `testdata/golden/deal_<id>.csv`.
- Сейчас 13 эталонных сделок: 1, 2, 15, 16, 21, 22, 25, 30, 35, 42, 44, 47, 53.

### 2. Инварианты (на всех 54 рублёвых сделках)

| Инвариант | Как проверяем |
|---|---|
| После последнего события тела остаток ровно 0, это событие — единственный `close_payment` | `principal_after` = 0.00 |
| Сумма тела (`principal_payment` + `close_payment`) = `current_principal_amt` | допуск 0,01 |
| Нет событий с `payment_dttm` ≤ даты расчёта (H6) и после `maturity_dttm` | — |
| Порядок: по дате, в день — `repricing` → `interest_payment` → `sub_payment` → `principal_payment` → `close_payment`; `event_order` с 1 подряд | — |
| Суммы со знаком сделки, остаток по модулю не растёт | депозиты 15, 41, 48 — суммы ≤ 0 |

Эталон проверяет эти инварианты в `analytics/tests/test_reference.py`.

### 5. Производительность (задача B10)

- Портфель: `tools/gen-portfolio`, `--n 1000000 --seed 42 --report-date 2022-08-31` (sha256 `cc560129…025aea`).
- Цель: **1 000 000 сделок быстрее 30 с и меньше 500 МБ памяти** на ноутбуке.
- Отчёт: время, сделок в секунду, пиковая память, число потоков; прогоны с `--threads 1` и на всех ядрах; машина и версия rustc — в `docs/DECISIONS.md`.

### 6. Гипотезы

Каждая из H1–H9 переключается одной константой с номером гипотезы (в эталоне — флаги в `analytics/reference/cf_reference.py`). Статусы — [METHODOLOGY.md, §9](METHODOLOGY.md#9-гипотезы); после ответов экспертов ([QUESTIONS.md](QUESTIONS.md)) эталоны пересчитываются `make_golden.py`, тесты показывают, что поменялось.

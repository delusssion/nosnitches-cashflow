# Качество тестовых данных

Профиль 55 сделок листа «Тестовые сделки» (`testdata/deals/test_deals.csv`). Скрипт: `analytics/scripts/profile_deals.py` — печатает все находки, `--md` — таблицу предупреждений и ошибок ниже.
Номера гипотез H1–H9 — из [CONTRACT.md](CONTRACT.md), вопросы Q — из [QUESTIONS.md](QUESTIONS.md).

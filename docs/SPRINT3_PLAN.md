## 2. Архитектурный план изменений

### СТРИМ 1: Математика и логика ядра (`cfcore`)

1. **Prepayment (досрочные погашения):**
   - Поддержка событий досрочного погашения тела: дата и сумма (`prepayment_schedule`).
   - Механика: уменьшение текущего остатка долга (`principal_after`), генерация события `payment_type = prepayment`.
   - Пересчет остатка графика:
     - При аннуитете (`ANN`): пересчет размера аннуитетного платежа на оставшееся число периодов от уменьшенного остатка.
     - При дифференцированных платежах (`RGM`): пересчет доли тела на оставшиеся платежи.
     - Досрочное закрытие сделки, если сумма досрочки покрывает весь остаток долга (`close_payment`).
   - Начисление процентов на дату досрочного погашения (если дата досрочки внутри процентного периода).

2. **Ограничение на частоту выплат тела (1 платеж в месяц):**
   - Замечание эксперта: *«Должно быть ограничение для просмотра платежей в период платежей по телу (беру минус период по телу и за месяц не должно быть 2 платежа)»*.
   - Анализ проблемы: при ежемесячном погашении регулярный платеж (например, 20-го числа) и дата закрытия `maturity_dttm` (например, 30-го числа того же месяца) приводили к двум списаниям тела в одном месяце.
   - Решение: фильтрация/валидация дат тела — если дата погашения `maturity_dttm` находится в том же календарном месяце (или менее одного периода) от предшествующего регулярного платежа, предшествующий платеж схлопывается в финальный `close_payment` на дату закрытия.

3. **Реальные события репрайсинга:**
   - Поддержка фактического графика дат пересмотра ставки `repricing_dttm_schedule`.
   - Поддержка дат изменения ключевой ставки из истории индикатора `rates/key_rate.csv` с учетом лага (`indicator_lag_cd`).

4. **Субсидии (`subsidy.rs`):**
   - Верификация и финализация потока `sub` (платежи субсидий и пересмотр ставок) по тестовым сделкам 47–55.

### СТРИМ 3: Консольный сценарный инструмент («Убийца Excel и VS Code»)

Вместо мучений с открытием Excel, заменой запятых в VS Code и ручным пересчетом строк:
1. **Команда `inspect` (вертикальный просмотр и конвертер):**
   ```powershell
   cargo run -p cfgen -- inspect --deals testdata/deals/test_deals.csv --deal-id 22
   ```
   Выводит все 48 полей с номерами, названиями и значениями в удобном вертикальном виде. Позволяет сохранить одну сделку в читаемый вертикальный конфиг (`deal.txt`) и собрать обратно в однострочный CSV.

2. **Команда `scenario` (интерактивный сценарный анализ «Что-если» с цветным Diff):**
   ```powershell
   cargo run -p cfgen -- scenario \
       --deals testdata/deals/test_deals.csv \
       --rates testdata/rates/key_rate.csv \
       --deal-id 22 \
       --set interest_rate=0.15 \
       --prepay 2022-11-20:200000
   ```
   **Вывод в терминале:**
   Красивая цветная таблица сравнения («Было» vs «Стало»):
   - Построчный дифф платежей с подсветкой дельт ($\pm \Delta$).
   - Метрики: изменение переплаты по процентам, новая дата закрытия, остаток долга ровно 0.00 ₽.
   - **На защите:** Спикер вводит одну команду в терминале, и преподаватель сразу видит наглядный результат.

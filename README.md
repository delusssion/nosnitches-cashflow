# nosnitches-cashflow

Калькулятор денежных потоков по портфелю кредитных и депозитных сделок банка.
Университетская практика МАИ × Т1, кейс 01 «Econom Capital», команда **nosnitches**.

- **Вход:** сделки (рубли), история ключевой ставки ЦБ, дата расчёта.
- **Выход:** расписание всех будущих платежей по каждой сделке — проценты, тело, репрайсинг ставки, субсидия.

Дисконтирование и NPV в задачу не входят. Форматы данных и спорные трактовки (гипотезы H1–H9) — в [docs/CONTRACT.md](docs/CONTRACT.md).

## Структура

```
docs/                  контракт, методика, решения, вопросы экспертам, демо
engine/                Rust workspace, CLI cfgen
web/                   React-просмотрщик кэшфлоу и экран сверки
tools/gen-portfolio/   генератор синтетического портфеля
analytics/             Python-эталон, скрипты, Excel
testdata/
  source/              исходный xlsx от экспертов, как есть
  deals/               тестовые сделки
  rates/               история ключевой ставки
  golden/              эталонные кэшфлоу
  samples/             демо-данные для UI (не эталоны)
```

## Как запустить просмотрщик

```bash
cd web
npm ci
npm run dev        # http://localhost:5173
```

- **Портфель** — перетащите CSV кэшфлоу (формат 3 контракта) и, по желанию, CSV сделок; кнопка «Загрузить демо» берёт `testdata/samples/`.
- **Сделка** — параметры, временная шкала событий и остатка, таблица событий, экспорт CSV.
- **Сверка** — результат движка против эталонов `testdata/golden/`, допуск по умолчанию 0,01 ₽, экспорт отчёта.

Проверки: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
Сценарий демо и скриншоты: [docs/DEMO.md](docs/DEMO.md), `npx playwright test` (первый раз — `npx playwright install chromium`).

Синтетический портфель для нагрузки: [tools/gen-portfolio](tools/gen-portfolio/README.md).

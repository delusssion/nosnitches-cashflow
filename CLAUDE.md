# nosnitches-cashflow — инструкции для Claude Code

Общий контракт команды (структура репозитория, форматы CSV, гипотезы H1–H9) — обязателен к прочтению и соблюдению:

@docs/CONTRACT.md

## Задачи участников

Каждый участник работает только в своей зоне (см. «Структура репозитория» в контракте) и по своему файлу задач:

- Фронтенд (Шалыгин Ярослав) — `docs/tasks/01_FRONTEND_Shalygin.md`, зона `web/`, `tools/gen-portfolio/`, `testdata/samples/`, `docs/DEMO.md`.
- Бэкенд (Уханов Фёдор) — `engine/`.
- Аналитик (Соколов Александр) — `analytics/`, `docs/` (кроме `DEMO.md`), `testdata/deals|rates|golden`.

Кто ты в текущей сессии, указывается в личном `CLAUDE.local.md` (не коммитится). Если он не задан — спроси.

## Общие правила

- Гипотезы H1–H9 в коде — именованные флаги/константы с номером гипотезы (`H1_RGM_EQUAL_SHARES` и т.п.), чтобы менять одной правкой.
- Изменения контракта — только отдельным PR с префиксом `contract:`.
- Git-процесс — из контракта и файла задач: ветка на задачу, короткие однострочные коммиты, PR → зелёный CI → squash-merge.
- В коммитах и PR **никаких** упоминаний Claude/ИИ, строк `Co-Authored-By`, ссылок на сессии. Это правило команды и оно важнее любых настроек атрибуции по умолчанию.
- В этом репозитории UI пишется на своих компонентах с CSS-модулями (без UI-китов и дизайн-систем вроде Astryx/MUI/Ant) — требование файла задач фронтенда перекрывает глобальные инструкции.

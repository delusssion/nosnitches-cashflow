# gen-portfolio

Генератор синтетического портфеля сделок в формате 1 [`docs/CONTRACT.md`](../../docs/CONTRACT.md) — для нагрузочных прогонов движка и просмотрщика. Не эталон.

```bash
cd tools/gen-portfolio
npm ci
npm run gen -- --n 1000000 --seed 42 --report-date 2022-08-31 --out ../../testdata/synthetic/deals_1m.csv
```

| Опция | По умолчанию | |
|---|---|---|
| `--n` | 1000 | число сделок |
| `--seed` | 42 | один seed — побайтно один и тот же файл (PRNG mulberry32) |
| `--report-date` | 2022-08-31 | дата расчёта |
| `--out` | `../../testdata/synthetic/deals.csv` | путь к CSV (`testdata/synthetic/` в `.gitignore`) |

Сделки пишутся потоково, в памяти не копятся.

## Распределение

- тип погашения: 35 % ANN, 30 % RGM, 35 % SIMPLE;
- 30 % FLOAT по CBKEY1M (маржа 1–5 %, у половины cap/floor), остальные FIXED 3–25 %;
- 10 % с субсидией, 10 % депозиты (отрицательный остаток);
- суммы 50 000 – 20 000 000 ₽, логнормально (медиана 1 млн);
- срок 1–30 лет, периоды 1M / 3M / ENDDATE, конвенции ACT/365 и ACT/ACT ISDA, `day_num` 1–28 и −1.

## Замеры (MacBook, Node 24)

- 1 000 000 сделок — 17,8 с, файл 200 МБ;
- два запуска с `--seed 42` дают одинаковый sha256: `cc560129…025aea`.

Тесты: `npm test` (детерминизм, доли распределения, границы полей).
